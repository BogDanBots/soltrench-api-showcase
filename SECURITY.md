# Security policy

This repository contains documentation and redacted screenshots only. It does
not contain the production API, credentials, private endpoints, or signing
material.

Please do not publish suspected credentials or private customer information in
an issue or pull request. Contact the repository owner through the
[BogDanBots GitHub profile](https://github.com/BogDanBots) with the affected
file, a minimal reproduction, and the impact. Never submit a seed phrase,
private key, API key, cookie, or RPC credential.

The production implementation is maintained in a separate private repository;
this case study is not an audit or a security guarantee.
